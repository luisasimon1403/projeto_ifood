# Food Delivery System in C

Console-based food delivery application inspired by modern delivery platforms.

Developed in C language with focus on programming logic, data structures, menus, user flow, and CRUD operations.

## Features

### User Module
- User registration
- Login system
- Account management
- Edit personal data
- Change password
- Marketing preferences

### Restaurant Module
- Product catalog
- Product details
- Stock management
- Dynamic menu

### Shopping Cart
- Add products
- Remove items
- Automatic total calculation
- Order checkout

### Payment Methods
- Credit Card
- Cash
- Pix QR Code simulation

### Delivery Tracking
- Order received
- Preparing order
- Out for delivery
- Delivered

### Admin Module
- Admin login
- Add products
- Edit products
- Delete products
- Manage stock

## Technologies Used

- C Language
- Structs
- Arrays
- Functions
- Conditionals
- Loops
- Console UI

## Purpose

Academic project created to simulate a real-world delivery platform and practice software development fundamentals.
